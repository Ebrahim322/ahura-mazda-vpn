# آی‌پی تمیز اهورا (Ahura Clean IP)

اپ اندرویدی که **آی‌پی‌های سالم لبهٔ CDN** را پیدا می‌کند تا در برنامهٔ **شیر و خورشید**
(حالت *فرانتینگ CDN*) و کلاینت‌های v2ray بگذاری و وصل شوی.

* **دانلود:** [`cleanip.apk`](cleanip.apk) — حدود ۱۳۰ کیلوبایت، اندروید ۷ به بالا، بدون تبلیغ
* صفحهٔ دانلود: [`index.html`](index.html)
* هستهٔ اسکن بدون اندروید تست می‌شود: `./test/run-tests.sh` (۷۰ بررسی، همه سبز)

---

## چرا این اپ؟

برنامهٔ شیر و خورشید در حالت *فرانتینگ CDN* دو کادر دارد:

| کادر در شیر و خورشید | چه چیزی می‌خواهد | خروجی این اپ |
|---|---|---|
| **ای‌پی‌های لبه CDN** | آی‌پی یا CIDR، جدا شده با کاما/فاصله/خط جدید | دکمهٔ «کپی آی‌پی‌ها» |
| **نام‌های میزبان SNI برای CDN** | نام میزبان (دامنه) | دکمهٔ «کپی دامنه (SNI)» |

آی‌پی‌های خام زیاد هستند ولی بیشترشان روی شبکهٔ ایران باز نمی‌شوند. این اپ همان کاری را
می‌کند که خود تانل می‌کند و فقط آی‌پی‌هایی را نگه می‌دارد که واقعاً جواب می‌دهند:

1. **اتصال TCP** به `آی‌پی:پورت`
2. **دست‌دادن TLS** با همان **SNI** دامنهٔ شما و با **ALPN `http/1.1`**
   (پروتکل‌های `FRONTED-MEEK-CDN-OSSH` و `FRONTED-MEEK-CDN-HTTP-OSSH` تانل همین را می‌خواهند)
3. **بررسی گواهی TLS و نام میزبان** (قابل خاموش کردن) — همان کاری که تانل می‌کند،
   پس آی‌پی‌هایی که گواهی‌شان با SNI نمی‌خواند (یا صفحهٔ مسدودسازی پشتشان است) رد می‌شوند
4. **یک درخواست HTTP** و خواندن پاسخ: اگر سرور `cf-ray` بدهد یعنی واقعاً لبهٔ کلادفلر است
5. (اختیاری) **تست سرعت دانلود** روی نتایج برتر، مثلاً `speed.cloudflare.com/__down`

صفحه‌های مسدودسازی اپراتور (پاسخ‌هایی که متن‌هایی مثل «مسدود» یا `10.10.34.34`
دارند) خودکار شناسایی و حذف می‌شوند.

## روش استفاده

### ۱) در این اپ
1. دامنهٔ فرانتینگ (همان SNI کانفیگت) را بزن — پیش‌فرض `speed.cloudflare.com`.
2. منبع آی‌پی را انتخاب کن: **رنج‌های کلادفلر** (نمونه‌برداری تصادفی از همهٔ رنج‌ها)،
   **لیست دستی** (آی‌پی/CIDR/بازه) یا **حول یک دامنه** (آی‌پی دامنه را با DNS پیدا می‌کند و
   کل `/۲۴` اطرافش را اسکن می‌کند تا همسایه‌های تمیز همان لبه را پیدا کند).
3. پورت‌ها: برای شیر و خورشید فقط **۴۴۳** و **۸۰** لازم است (بقیه برای کلاینت‌های دیگر).
4. «شروع اسکن» → نتیجهٔ زندهٔ سالم‌ها را می‌بینی (پینگ، وضعیت TCP/TLS، برچسب کیفیت).
5. تمام که شد: **«کپی آی‌پی‌ها»**. (نگه‌داشتن انگشت روی همان دکمه = کپی به‌شکل CIDR
   برای رنج‌های پیوسته.)

### ۲) در شیر و خورشید
1. **Options → More Options**.
2. «انتخاب پروتکل» را روی **فرانتینگ CDN** بگذار.
3. در بخش «فرانتینگ CDN» → **ای‌پی‌های لبه CDN** → آی‌پی‌ها را پیست کن.
4. در **نام‌های میزبان SNI برای CDN** → دامنه را پیست کن (دکمهٔ «کپی دامنه»).
5. برگرد به صفحهٔ اصلی و وصل شو؛ چند ثانیه صبر کن تا مسیر سالم انتخاب شود.

> نکته: اگر روی همان شبکه‌ای اسکن کنی که می‌خواهی وصل شوی (همان اپراتور/VPN)، نتیجه
> دقیق‌تر است. برای حالت QUIC همان لیست آی‌پی را می‌توانی استفاده کنی.

## خروجی‌ها

* **کپی آی‌پی‌ها** — یک آی‌پی در هر خط، آمادهٔ پیست در کادر «ای‌پی‌های لبه CDN».
* **کپی دامنه (SNI)** — برای کادر دوم.
* **کپی آی‌پی:پورت** — برای کلاینت‌های دیگر.
* **کانفیگ‌ها** — ساخت لینک `vless` / `trojan` / `vmess` از نتایج سالم
  (شبکهٔ ws/grpc/tcp/httpupgrade، مسیر، Host، SNI، fp، ALPN، serviceName).
  دکمهٔ «پرکردن از کلیپ‌بورد» یک کانفیگ آماده را پارس می‌کند و فیلدها را پر می‌کند؛
  «پیش‌فرض BPB» مسیر `/?ed=2560` را می‌گذارد.
* **گزارش کامل / اشتراک / ذخیره در Downloads** — فایل `cleanip-<دامنه>-<تاریخ>.txt`
  در `Downloads/AhuraCleanIP/`.
* **خلاصهٔ رنج‌ها** — کدام بلوک‌های `/۲۴` بیشترین آی‌پی سالم را دارند.

## ساخت و تست

نیاز به اندروید استودیو یا SDK نیست؛ کل زنجیرهٔ ابزار (~۷۰ مگابایت) در `~/.toolchain`
نصب می‌شود:

```bash
cd cleanip
./build.sh              # خروجی: cleanip.apk  (ECJ → D8 → aapt2 → zipalign → apksigner)
./test/run-tests.sh     # تست هستهٔ اسکن روی JVM: ۷۰ بررسی
```

`test/run-tests.sh` یک سرور TLS محلی با گواهی self-signed می‌سازد و همان مسیر واقعی
(TCP → TLS با SNI و ALPN → HTTP → تست سرعت)، رد شدن گواهی نامعتبر، صفحهٔ مسدودسازی،
لغو اسکن و پارس/ساخت کانفیگ‌ها را بررسی می‌کند.

## محدودیت‌ها

* این اپ خودش VPN نیست؛ فقط مسیر را اندازه می‌گیرد و لیست می‌دهد.
* اسکن از خود گوشی انجام می‌شود؛ هیچ داده‌ای جایی ارسال نمی‌شود (فقط دانلود لیست
  رسمی رنج‌های کلادفلر، آن هم در صورت روشن بودن گزینه‌اش).
* DNS ایرانی ممکن است آی‌پی دامنه را درست نشان ندهد؛ در حالت «حول یک دامنه» می‌توانی
  آی‌پی مرجع را دستی بدهی.
* ترافیک اسکن چندان زیاد نیست، ولی روی بسته‌های حجمی با احتیاط (تعداد کم‌تر، تست سرعت خاموش).
