## ۱) آی‌پی تمیز اهورا — اسکنر آی‌پی سالم CDN

اپی که آی‌پی‌های سالم لبهٔ CDN (کلادفلر، فستلی و…) را پیدا می‌کند تا در کلاینت
**شیر و خورشید** (حالت *فرانتینگ CDN*) و کلاینت‌های v2ray بگذاری و وصل شوی.

* **دانلود:** [`cleanip/cleanip.apk`](cleanip/cleanip.apk) — ۱۳۰ کیلوبایت، اندروید ۷ به بالا
* صفحهٔ معرفی: [`cleanip/index.html`](cleanip/index.html)
* مستندات: [`cleanip/README.md`](cleanip/README.md)

تست دقیقاً مثل خود تانل انجام می‌شود: اتصال TCP → دست‌دادن TLS با SNI و ALPN
`http/1.1` → بررسی گواهی → درخواست HTTP (تشخیص لبهٔ واقعی با `cf-ray`) → تست سرعت.
خروجی: لیستی آمادهٔ پیست در فیلد «ای‌پی‌های لبه CDN» به‌همراه دامنه برای فیلد SNI،
و در صورت نیاز کانفیگ‌های vless/vmess/trojan.

```bash
cd cleanip
./build.sh            # خروجی: cleanip.apk
./test/run-tests.sh   # ۷۰ بررسی روی هستهٔ اسکن (روی JVM، بدون گوشی)
```
