# راه‌اندازی آهورا مزدا — نسخهٔ ۱.۱ (فارسی)

## ۱) اپ را نصب کنید (APK آماده است)

آخرین نسخهٔ ساخته‌شده را از اینجا دانلود کنید:

```
https://github.com/Ebrahim322/ahura-mazda-vpn/releases/latest
```

فایل `app-debug.apk` (حدود ۹۰۰ کیلوبایت) را روی گوشی اندروید نصب کنید.
اندروید اجازهٔ «نصب از منابع ناشناس» می‌خواهد — طبیعی است، APK با کلید دیباگ
امضا شده و از بیرون استور نصب می‌شود. `minSdk 24` (اندروید ۷ به بالا).

اگر خودتان می‌خواهید بسازید:

```bash
cd android
gradle wrapper --gradle-version 8.9   # یک‌بار
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## ۲) سرور رله را با یک خط نصب کنید

روی VPS (اوبونتو/دبیان/فدورا/آلپاین، دسترسی root):

```bash
curl -fsSL https://raw.githubusercontent.com/Ebrahim322/ahura-mazda-vpn/main/server/install.sh | sudo bash
```

تا زمانی که این شاخه در `main` مرج نشده، همان دستور را با آرگومان شاخه بزنید:

```bash
curl -fsSL https://raw.githubusercontent.com/Ebrahim322/ahura-mazda-vpn/arena/01a0e85b-ahura-mazda-vpn/server/install.sh \
  | sudo bash -s -- --branch arena/01a0e85b-ahura-mazda-vpn
```

این اسکریپت: کاربر سیستمی `ahura` می‌سازد، رله را دانلود می‌کند، کلید مخفی و
توکن می‌سازد، `/etc/ahura-relay/config.json` را می‌نویسد، سرویس systemd را
نصب و روشن می‌کند، پورت را در ufw/firewalld/nftables باز می‌کند و در آخر یک
لینک آمادهٔ اپ چاپ می‌کند:

```
ahura://relay@203.0.113.9:1080?key=<hex>&token=phone-ab12&obfs=any&name=vps
```

گزینه‌ها: `--port`, `--token`, `--stealth-key`, `--obfs any|tls|ahura/1|none`,
`--public-host`, `--dashboard-port`, `--no-firewall`, `--uninstall`, `--branch`.

## ۳) در اپ وصل شوید

1. تب **سرورها** → دکمهٔ **درون‌ریزی**: لینک `ahura://…` را از پیام‌رسان کپی
   کنید (یا کل لینک را لمس کنید تا اپ باز شود و سرور خودکار اضافه شود).
2. دکمهٔ **تست همه سرورها** را بزنید: زمان دست‌دادن هر سرور کنار نامش می‌آید.
   گزینهٔ **انتخاب خودکار سریع‌ترین سرور** (پیش‌فرض روشن) اپ را به سریع‌ترین
   سرورِ جواب‌دهنده وصل می‌کند و هر ۲ دقیقه چک می‌کند؛ اگر آن سرور از کار
   بیفتد، خودکار به سرور بعدی می‌رود.
3. حالت پنهان‌سازی هر سرور در پنجرهٔ افزودن/ویرایش انتخاب می‌شود:
   * **TLS نما (پیشنهادی)** — ترافیک شکل رکوردهای TLS 1.2 را دارد
     (`16 03 01 …` در ابتدای نشست، `17 03 03 …` برای داده، طول‌های تصادفی).
   * **AHURA/1 فشرده** — سریع‌تر، بدون شبیه‌سازی TLS.
   * **SOCKS5 خام** — بدون پنهان‌سازی (برای سازگاری با کلاینت‌های دیگر).
4. تب **قواعد آی‌پی**: «همه ترافیک» یا «فقط فهرست زیر» با یک CIDR در هر خط:
   `8.8.8.8/32` (تونل)، `!192.168.0.0/16` (عبور مستقیم)، `block 5.5.5.5/32`
   (قطعی). کادر آزمایش، تصمیم موتور را برای هر آدرسی که بنویسید نشان می‌دهد.
5. دکمهٔ **اتصال**. کاشی تنظیمات سریع و راه‌اندازی خودکار پس از بوت هم هست.

## ۴) پنل سرور

روی خود VPS: `http://127.0.0.1:8080/` (فقط از خود سرور قابل دسترسی است) —
نمودار ترافیک، نشست‌های فعال، مصرف به تفکیک توکن، مقصدهای پرترافیک، خطاها،
گزارش زنده و همان **لینک `ahura://`** برای ایمپورت در اپ.

## ۵) اگر خواستید خودتان تست کنید

```bash
python3 server/tools/self_test.py    # ۲۴ تست پروتکل و رله (بدون اینترنت)
python3 server/tools/live_probe.py   # درخواست واقعی HTTP از داخل تونل، هر دو حالت
python3 server/tools/ahura_client.py --host 127.0.0.1 --port 1080 \
    --key <کلید> --token <توکن> --obfs tls --target 1.1.1.1:80 --probe
```

## محدودیت‌ها (صادقانه)

* `tls` شکل ترافیک را عوض می‌کند و بازرسی محتوا را بی‌فایده می‌کند، اما
  handshake واقعی TLS نیست (گواهی و تبادل کلید ندارد). در برابر تطبیق الگو و
  فیلترینگ دامنه/پروتکل مؤثر است، در برابر کسی که خودِ پورت را فعالانه بررسی
  کند نه.
* جابه‌جایی خودکار سرور، تانل را بازمی‌سازد (اتصال‌های زنده قطع می‌شوند) و فقط
  وقتی رخ می‌دهد که سرور فعال دیگر جواب ندهد.
* IPv4 fragment و هدرهای افزونهٔ پیچیدهٔ IPv6 عبور داده نمی‌شوند؛ UDP سقف
  تعداد و idle-timeout دارد.
* APK با کلید دیباگ امضا شده است؛ برای انتشار عمومی کلید خودتان را بسازید.
