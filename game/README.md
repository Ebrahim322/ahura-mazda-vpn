# نبرد اهورا (Ahura War)

یک بازی جنگیِ اکشن برای اندروید: تانک شما در برابر موج‌های بی‌پایان دشمن.
بازی با **Java خالص + Canvas** نوشته شده، هیچ وابستگی خارجی (و حتی یک فایل صوتی
یا تصویری) ندارد و کل APK حدود **۱۲۰ کیلوبایت** است.

* **دانلود:** [`ahura-war.apk`](ahura-war.apk) (یا از صفحهٔ [`index.html`](index.html))
* حداقل اندروید: ۶٫۰ (API 23) · هدف: اندروید ۱۴ (API 34)
* دسترسی‌ها: فقط `VIBRATE` — آفلاین، بدون تبلیغ، بدون اینترنت

## کنترل‌ها

| عمل | لمس | کیبورد |
|---|---|---|
| حرکت | نیمهٔ چپ صفحه (جوی‌استیک شناور) | `WASD` / کلیدهای جهت |
| شلیک | نیمهٔ راست صفحه | `Space` |
| پشتیبانی هوایی | دکمهٔ آبی بالای دکمهٔ آتش | `Q` |
| توقف | دکمهٔ بالا-راست | `Back` / `Esc` |

## ساخت APK

کل ابزارِ لازم حدود ۷۰ مگابایت است و در پوشهٔ `~/.toolchain` (بیرون از ریپو)
نصب می‌شود:

```bash
cd game
./build.sh            # خروجی: ahura-war.apk
```

`build.sh` این مراحل را انجام می‌دهد:

1. `tools/fetch-tools.sh` — دریافت JRE (از بستهٔ پایتونی `jdk4py`) و
   `aapt2` و همچنین `d8`، `apksigner`، کامپایلر `ecj` و `android.jar`
   (از بستهٔ npm شرکت `@drxiaozhi/minapk`).
2. کامپایل جاوا با **ECJ** در برابر `android.jar` (سطح ۸).
3. تبدیل کلاس‌ها به `classes.dex` با **D8** (`--min-api 23`).
4. بسته‌بندی منابع با **aapt2** و افزودن dex.
5. `tools/zipalign.py` — هم‌ترازسازی ۴ بایتی.
6. امضا با **apksigner** (v1 + v2) با کلید `ahura.keystore` (ساخته می‌شود اگر نباشد).

برای ساخت روی دستگاه دیگر فقط `bash`، `python3` و `curl`/`wget` لازم است —
نیازی به اندروید استودیو یا اندروید SDK نیست.

## تست و پیش‌نمایش

هستهٔ شبیه‌سازی بازی (`sim`) هیچ وابستگی به اندروید ندارد، بنابراین می‌توان آن را
روی JVM معمولی تست کرد:

```bash
./test/run-tests.sh     # تست منطق نبرد (امواج، باس، قدرت‌ها، کارایی)
./test/preview.sh       # رندر صفحه‌های بازی در .preview/*.png با یک Canvasِ تقلبی
```

## ساختار پروژه

```
game/
  AndroidManifest.xml        مانیفست (افقی، تمام‌صفحه)
  res/                       آیکون و رشته‌ها
  src/com/ahuramazda/war/
      MainActivity.java      اکتیویتیِ تمام‌صفحه
      GameView.java          حلقهٔ بازی، ورودی‌ها، وضعیت صفحه‌ها
      Renderer.java          رسم میدان نبرد (همه‌چیز با Canvas کشیده می‌شود)
      Ui.java                HUD، منوها و دکمه‌ها (متن‌های فارسی)
      Audio.java             سینتی‌سایزر نرم‌افزاری (افکت‌ها + موسیقیِ بی‌پایان)
      Save.java              بهترین امتیاز و تنظیمات (SharedPreferences)
      Theme.java             پالت رنگ و متن‌های فارسی
      sim/                   هستهٔ بازی، بدون وابستگی به اندروید
  tools/                     ابزار کمکی (دریافت ابزار، zipalign، آیکون)
  test/                      تست headless و پیش‌نمایش تصویری
  site/                      صفحهٔ دانلود
```

## نکته دربارهٔ کلید امضا

`ahura.keystore` همراه پروژه است تا نصبِ نسخه‌های بعدی بدون حذف نسخهٔ قبلی
انجام شود. برای انتشار جدی، کلید خودتان را بسازید و این فایل را عوض کنید.
